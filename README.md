## Summary

A fork of [MisterPrada/singularity](https://github.com/MisterPrada/singularity). A black hole visualization built with Three.js and TSL, running on WebGPU or WebGL.

## What's inside

`src/`, `static/`, `vite.config.js` and `package.json`.

## How to view or run it

See the commands above (`npm i`, then `npm run dev`). The upstream live version is at https://singularity.misterprada.com.
